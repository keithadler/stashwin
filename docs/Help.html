Stash for Windows Help

Encrypted backup of the folders that matter, into the storage you already have. The provider only ever sees ciphertext. Your key is 24 words on a card. No password, no recovery, no server.

Getting started

  1. Make a key. The app shows a card with 24 words. Write them down, save the card as text, or print it. It asks you for three of the words to prove you have it. Stash keeps no copy.
  2. Add folders. Documents, Pictures, Desktop, a project. Whole drives are refused; choose the folders that matter.
  3. Add destinations. The app offers the OneDrive, Google Drive, Dropbox or iCloud folders it finds on this PC. Any other folder, an external disk or a NAS works too. Two are safer than one.
  4. Back Up Now. Then set a schedule in Settings.

The key and the card

The key is 256 random bits, shown as 24 words from a fixed list with a checksum, so a mistyped word is caught before any restore starts. The eight-character fingerprint tells two cards apart. On this PC the key is wrapped by Windows Data Protection for your account; on the card it is the only other copy.

Lose the card and the backup is unreadable, by anyone, including you. There is no password to reset and no support line that can help. Treat the card like a passport.

Forget this key removes it from this PC. The backups stay where they are, encrypted, and the card brings them back on any PC or Mac.

Where it goes

Inside each destination the app makes a folder called Stash for Mac (the name the format was born with, kept so one card restores on either), then a folder named by the key's fingerprint, then chunks and manifests. Every file in there is encrypted. A README explains that to anyone who finds it.

Pieces are 4 MB, named by a keyed hash of their contents, so an unchanged file is stored once and shared by every snapshot. The provider cannot tell what a piece is, or whether two people stored the same file.

A destination that is not reachable (an unplugged disk, a NAS that is off) is skipped and the app says so. A cloud folder set to keep files online-only still works as a destination; the app only ever writes there.

Schedule

Settings offers every hour or once a day at 20:00. The app registers a Task Scheduler task for your account that runs stash.exe backup --scheduled, so backups happen whether or not the window is open, with no service and no administrator. Set it to off and the task is removed.

Restore and verify

Restore on a snapshot opens a list of every file in it. Select some, or restore everything, and choose where they go: files arrive in a folder named after the original folder, and nothing at the original location is touched. A piece that fails its authentication check is reported and never written.

Verify opens every piece the latest snapshot uses and restores one random file to a temporary folder to prove the whole path works. Pieces a cloud folder keeps online-only are counted, not downloaded. Settings can run this once a week.

Snapshots

Every backup is a snapshot: the list of files at that moment and the pieces that rebuild them. Frees is what deleting that snapshot alone gives back, the old versions only it still holds. After each backup the app keeps the newest N (30 by default) or thins out over time: everything from the last week, one a day for a month, one a week for a year, one a month after that. A piece nobody references is deleted, except one written in the last two hours, which may be an upload in flight from another PC on the same card.

With Stash for Mac

Same format, same words. Enter a Mac's card here and add the same destination folder: the Mac's snapshots appear and restore. Make a key here and a Mac reads this PC's backups. Both apps can back up to one destination with one card; the pieces they share are stored once.

Honest limits

  • Cloud placeholders (files a provider has not downloaded to this PC) are listed as skipped, never fetched. Open the file once, or mark the folder "always keep on this device", and the next backup takes it.
  • The provider, or anyone with your provider password, can delete the whole folder. Two destinations.
  • Someone with your unlocked PC and the app running has the key. No backup tool survives that.
  • Pieces are fixed 4 MB; a large file with a small edit in the middle uploads two new pieces, not a few bytes.
  • Windows Data Protection ties the wrapped key to your account on this PC: a new PC, a new account or a reset needs the card.

Command line

stash.exe is the same program as a console app.

stash key new | show | card <file.txt> | restore "<24 words>" | forget
stash add <folder>        stash dest <folder>        stash providers
stash backup [--json]    stash snapshots            stash restore latest <target> [--only a,b]
stash verify             stash prune [--keep N | --thin]    stash schedule off|hourly|daily
stash status [--json]    stash selftest

Exit codes: 0 fine, 1 something to look at, 2 problem, 64 usage. STASH_HOME moves the settings folder. Nothing leaves the PC except the encrypted backup. Free, MIT, built by Keith Adler; more at keithadler.github.io.
